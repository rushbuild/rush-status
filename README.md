# Rush status archive

Rush's maintained workload status and performance reports live with the source:

- [Workload status](https://github.com/rushbuild/rush/tree/main/docs/status)
- [Build performance](https://github.com/rushbuild/rush/tree/main/docs/benchmarks)
- [Source and contributions](https://github.com/rushbuild/rush)

This repository preserves historical reports, methodology corrections, graphs
and discussions. Its numbers describe their original candidates and workloads;
they do not certify a later release. Follow the maintained pages for current
validation and file new work in the source project's issue tracker.

The archived files and Git history remain available at their original paths.
